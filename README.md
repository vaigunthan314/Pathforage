PathForge 🚀
AI-Powered Personalized Career Learning Platform

Stop guessing what to learn next. Let your progress decide.

🎯 Problem

Students have many learning resources but struggle to know:

What to learn next
Which skills they are missing
Whether they are career-ready
Which projects to build
💡 Solution

PathForge creates a personalized journey based on the learner's career goal, level, progress, assessments and skill gaps.

Career Goal → Roadmap → Learn → Quiz → Track → Skill Gaps → Projects → Career Ready

✨ Key Features
Personalized career roadmap
Theory + YouTube learning resources
Topic quizzes and assessments
Skill-gap analysis
Context-aware AI Tutor
Career-relevant projects
Progress and career-readiness dashboard
Firebase authentication
🤖 AI

The AI Tutor uses learner context such as:
Career Goal + Level + Current Topic + Skill Gaps + Progress

It provides:

Simple explanations
Practical examples
Quizzes
Learning guidance
🏗️ Technology

Frontend: React, Vite, Tailwind CSS
Backend: Java, Spring Boot, REST API
Database: H2
Authentication: Firebase
AI: Groq API
Deployment: GitHub + Render

🏆 Innovation

PathForge follows a closed-loop learning model:

Learn → Assess → Measure → Identify Gaps → Adapt → Learn Next

This connects learning, skills, projects and AI into one career-focused platform.
